MD Tanjeel Imam - Personal Portfolio Website

HOW TO OPEN:
1. Extract the ZIP file if you downloaded the ZIP.
2. Open the folder.
3. Double-click index.html. It will open in your default browser (Chrome, Edge, etc.).

HOW TO EDIT:
Open index.html in VS Code or another text editor. Search for the text you want to change.
The site is a self-contained HTML file with its CSS and small JavaScript included.

PUBLISH ONLINE:
You can publish this folder using GitHub Pages or another static website host. The site is not online until you publish it.
